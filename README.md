# Cels extension repo

Aniframe adds this repository the way Anikku adds a Yuzono repository. The catalog file is `index.min.json`.

Installable packages are scripts that set `var source`. MangaDex is `scripts/all/mangadex.js`. The other rows are the website connectors collected in Cels. A row with an empty `apk` is listed, and Aniframe does not download a package for it.

```
https://raw.githubusercontent.com/demi-code/cels-repo/repo/index.min.json
```
